I'm a full stack developer, JavaScript enthusiast and UX specialist. I've been developing browser-based applications since 2005. I'm a hobbyist coder who loves what I do and consider myself a true craftsman with a focus on clean scalable code and elegant but intuitive UX.

An engineer since birth with the academic credentials to back it up — B.Eng and M.Eng from [DCU](https://dcu.ie). I'm also a member of [Engineers Ireland](https://www.engineersireland.ie/).

I wanted a portfolio site that reflected how I build things: lightweight, performant, and focused on the fundamentals. No bloated frameworks, no unnecessary dependencies — just HTML, CSS and enough JavaScript to make it a proper Progressive Web App.

The result was this site — a PWA designed to be as simple as possible. The UI is built to be as light and performant as possible, using basic CSS and semantic HTML to achieve an elegant style.

I have a passion for technology, especially cryptocurrencies, IoT and renewable energy. Outside of work I'm very interested in health and fitness — I love strength training and play 11-a-side football. I also like to surf and snowboard whenever I can.
